# Security

Text Alchemy does not collect telemetry, call remote services, or send note content over the network.

## Supported versions

Security fixes are provided for the latest published version.

If you find a security issue, report it through GitHub:

- Repository issues: https://github.com/NameIsKyro/text-alchemy/issues
- GitHub security advisories, if enabled on the repository

Please do not include private note content, secrets, tokens, or personal data in public reports. A minimal reproduction using placeholder text is enough.
